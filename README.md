# 🎱 Шар принятия решений

Режимы: Классика / Родблок / Астролог. Тап по шару или встряска телефона.
PWA: работает офлайн, ставится на главный экран.

## Публикация на GitHub Pages
1. Создать репозиторий (например `shar`) и загрузить все файлы в корень.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты: `https://toporviking1-creator.github.io/shar/`

## Обновление
После правок поменять `CACHE = 'shar-v1'` в `sw.js` на `shar-v2` и т.д., иначе телефоны покажут старую версию.
